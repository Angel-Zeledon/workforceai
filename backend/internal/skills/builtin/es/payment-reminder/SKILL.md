# Recordatorio de pago

## Cuándo usarla
Para reclamar amablemente el pago de una factura vencida o próxima a vencer.

## Pasos
1. Identifica la factura, el importe pendiente, la fecha de vencimiento y los días de retraso.
2. Elige el nivel de recordatorio según el atraso: amistoso, formal o último aviso.
3. Redacta el mensaje con la referencia, el importe exacto, la forma de pago y una sola acción pedida.
4. Incluye la fecha límite para confirmar el pago y el contacto para dudas.

## Criterios de calidad
- El tono es firme pero cordial, sin acusaciones ni amenazas.
- El importe y la referencia coinciden exactamente con la factura.
- Si el pago ya consta como recibido, no se genera el recordatorio.

## Límites
Deja el recordatorio como borrador para aprobación humana antes de enviarlo. No añadas recargos, intereses ni plazos que no estén en las condiciones acordadas.
