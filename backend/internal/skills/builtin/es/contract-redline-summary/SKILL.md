# Resumen de cambios entre versiones de un contrato

## Cuándo usarla
Cuando llega una nueva versión de un contrato, una contrapropuesta o un documento renegociado, y hay que entender el efecto de cada cambio antes de responder.

## Pasos
1. Confirma cuál es la versión base y cuál la nueva, con fecha y nombre de archivo, para no invertir la comparación.
2. Compara sección por sección, incluidas definiciones, anexos y referencias cruzadas. Marca adiciones, eliminaciones y cambios de redacción.
3. Ignora los cambios solo de formato o numeración, y di en el resumen que se omitieron.
4. Para cada cambio sustantivo indica el texto anterior y el nuevo entre comillas, quién se beneficia y el efecto en montos, plazos, riesgos o responsabilidades.
5. Clasifica cada cambio como aceptable, negociar o rechazar, con su motivo.
6. Cierra con los cambios clave y las preguntas que deben resolverse con la otra parte.

## Criterios de calidad
- Cada cambio sustantivo cita el texto antes y después.
- Ningún cambio queda sin reportar, incluidos los que afectan una cláusula indirectamente a través de una definición o referencia.
- El impacto se expresa con cifras concretas (montos, días, responsabilidades), no con adjetivos.
- Se distingue lo que cambió de lo que solo se reordenó.

## Límites
No reemplaza la revisión jurídica de la versión final. Aceptar o rechazar cambios lo decide una persona con autoridad para negociar.
