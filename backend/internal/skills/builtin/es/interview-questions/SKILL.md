# Preguntas de entrevista
## Cuándo usarla
Para preparar una entrevista con un guion común para todos los candidatos de un puesto.

## Pasos
1. Identifica de 3 a 5 competencias clave a partir de la descripción del puesto.
2. Redacta una pregunta abierta por competencia, centrada en experiencias pasadas concretas.
3. Para cada pregunta, indica qué respuesta sería sólida y qué señales serían de alerta.
4. Incluye una pregunta situacional y, si el puesto lo requiere, una de conocimientos técnicos.

## Criterios de calidad
- Todas las preguntas se relacionan con el trabajo y no con la vida personal.
- Ninguna pregunta sobre edad, estado civil, familia, religión u origen.
- El mismo guion se usa con todos los candidatos del puesto.

## Límites
Es un borrador para la persona entrevistadora; no evalúes ni decidas sobre candidatos a partir de este documento.
