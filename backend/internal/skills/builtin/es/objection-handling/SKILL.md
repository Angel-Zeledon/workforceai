# Manejo de objeciones

## Cuándo usarla
Cuando un prospecto plantea un reparo y necesitas una respuesta profesional.

## Pasos
1. Identifica el tipo de objeción: precio, tiempo, competencia, autoridad o necesidad.
2. Reformula la objeción con tus palabras para confirmar que la entiendes.
3. Pregunta qué hay detrás del reparo para descubrir el motivo real.
4. Responde con un argumento concreto ligado a su situación, usando solo datos disponibles.
5. Cierra con una pregunta que devuelva la conversación al siguiente paso.

## Criterios de calidad
- Reconoce la preocupación antes de rebatirla.
- Evita tonos defensivos y frases de presión.
- Cada respuesta cabe en tres o cuatro frases.

## Límites
Entrega las respuestas como guion de apoyo para el vendedor, no como texto final para el cliente. No prometas descuentos, plazos ni resultados que no estén autorizados en los datos.
