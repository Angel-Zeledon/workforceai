# Resumen de hoja de ruta

## Cuándo usarla
Para explicar el plan de producto a dirección, áreas internas o equipos.

## Pasos
1. Agrupa las iniciativas por tema u objetivo estratégico.
2. Para cada tema indica prioridad, hito principal y estado actual.
3. Señala los cambios desde la revisión anterior: añadidos, retrasados y eliminados.
4. Cierra con los dos o tres riesgos o decisiones pendientes más relevantes.

## Criterios de calidad
- Cada fecha o hito aparece tal como figura en los datos y se presenta como plan, no como compromiso.
- El resumen cabe en una página y se entiende sin contexto previo.
- Cada prioridad tiene una razón breve.

## Límites
Deja el resumen como borrador para aprobación de la persona responsable de producto. No modifiques prioridades ni prometas fechas.
