# KPI dashboard brief

## When to use it
To define what a dashboard must show before building it.

## Steps
1. State the decision the dashboard must support and who will use it.
2. Choose five to eight indicators, each with an exact definition.
3. Give the data source, refresh frequency and owner of each metric.
4. Set alert thresholds and separate the main view from the detail view.

## Quality criteria
- Each KPI has one definition, with no ambiguity about numerator or period.
- No indicator appears without a link to the stated decision.
- Thresholds are justified by a target or history, never invented.

## Limits
Leave the brief as a draft for approval by the audience. Do not set targets or figures that are not in the task data.
