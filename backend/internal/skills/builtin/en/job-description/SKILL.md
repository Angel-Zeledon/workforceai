# Job description
## When to use it
To create or update a job description before publishing a vacancy.

## Steps
1. Summarize the purpose of the role in one sentence and name the team it belongs to.
2. List 4 to 6 main responsibilities, starting each with an action verb.
3. Separate must-have from nice-to-have requirements; include years of experience or certifications only if the data states them.
4. Describe the work mode (on-site, remote or hybrid) and conditions using only the information available.

## Quality criteria
- Inclusive language and no unnecessary jargon.
- Every requirement can be verified in an interview or a resume.
- One page at most.

## Limits
Leave the text as a draft for HR review; do not publish the posting or invent salaries or benefits.
