# Grading rubric
## When to use it
When a task, project or performance exam needs clear criteria and described levels, so that assessment is consistent and understandable.

## Steps
1. Define the task to be assessed and the learning outcomes it measures.
2. Choose three to five observable criteria, each with a weight, and make sure the weights add up to 100.
3. Define four performance levels: excellent, good, sufficient and insufficient.
4. Describe each cell with concrete, observable evidence that differs from the neighboring cell, without empty adjectives.
5. Test the rubric on a sample piece of work and check that two people give similar scores.
6. Fill in the template `templates/rubric.csv` and add usage instructions for the assessor.

## Quality criteria
- The weights add up to exactly 100.
- Each level is distinguished from the next by an observable difference.
- No criterion measures the same thing as another.
- The descriptions refer to the work submitted, not to judgments about the person.

## Limits
The rubric is a proposal: the teacher or owner decides how it is used and adjusted. Do not assign final grades to individual work or use the rubric for disciplinary decisions.
