# Project plan

## When to use it
When there is a goal and it must be split into coordinated work.

## Steps
1. Write the goal, the expected outcome and measurable success criteria.
2. Define scope: what is in and what is out.
3. Split into milestones and tasks of at most 3 days; each task with an owner (role), an estimate and a dependency.
4. Mark the critical path and the tasks that can run in parallel.
5. List risks with probability, impact and mitigation; and the assumptions to confirm.
6. Use `templates/plan.md` as the delivery format.

## Quality criteria
- Every task has a verifiable result.
- Dependencies do not form cycles.
- Dates are relative to the start when no calendar was given.
