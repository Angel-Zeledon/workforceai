# Vendor comparison

## When to use it
To decide between several vendors or assess the renewal of an existing one.

## Steps
1. Define the decision criteria and their weights according to the priorities given in the task.
2. Build a table with each vendor against each criterion, using only data from the offers.
3. Calculate the comparable total cost, including taxes, shipping and payment terms.
4. Summarize the risks and a recommendation conditional on what still needs confirmation.

## Quality criteria
- All vendors are assessed with the same criteria and in the same currency.
- Each table value states its source or is marked as pending.
- The recommendation explains which criterion drives it.

## Limits
The recommendation is a proposal for the person making the purchase decision. Do not attribute prices, certifications or references that do not appear in the information provided.
