Skills: reusable know-how for your agents

A skill is a written guide an agent looks up while it works, for example how to reconcile a bank statement or write a weekly report. Here you learn to find skills, write or import your own, approve them and give them to an agent.

Understand what a skill does#

Each skill has a name, a description of when to use it and step-by-step instructions. It can include resource files, input and output examples and quality criteria.

On every task, the agent only sees the name and description of its skills. It receives the full text only if it asks for it.

Note

A skill only brings knowledge: it never grants tools, connections or permissions. The agent's role and your organization still decide that, and sensitive actions still ask for your approval.

Browse the built-in skills#

The library starts with 55 built-in skills, already active and written in Spanish or English. They carry the “Built-in” label and cover sales, finance, legal, human resources, support, product, data and engineering. For example:

  • Bank reconciliation and month-end close.
  • Lead qualification and sales call prep.
  • NDA review and service contract review.
  • Job descriptions and interview questions.
  • Support replies and complaint handling.
  • Product requirements, SQL query explanations and a code review checklist.

Tip

Your agents' roles already include some; on the skill they show as “From role”.

Find a skill#

  1. Open “Skills” in the side menu.
  2. Type a topic in “Search skills…”, for example “report” or “sales”. The list filters instantly.
  3. Filter by status with “All”, “Active”, “In review”, “Drafts” or “Disabled”; each filter shows how many there are.
  4. Click a card to open it and see its status, its source (“Built-in”, “Created”, “Imported” or “From a task”), its version and how many agents have it.

Tip

Skills in review open directly on the “Review” tab.

Read a skill before using it#

Each skill has four tabs:

TabWhat it shows
ContentThe description, the instructions and the resource files
ReviewEverything an agent would receive, with the “Scan warnings”
VersionsEvery saved version, with a “Restore” option
AgentsWho has it and whether it arrives “Assigned” or “From role”

Note

The scan warns, for example, about a “Possible instruction injection” or that the skill “Contains a script”. Scripts are stored as text and never run on their own: running one needs code.run with human approval.

Tip

You can take any skill with you using “Download .zip” or “Download SKILL.md”.

Create your own skill#

You can write it from scratch or start from work already done: in the “Tasks” tab of an agent's panel, a finished task offers “Save as skill”, which pre-fills the draft.

  1. Press “New skill”.
  2. Write the “Name” in lowercase letters, digits and hyphens, for example bank-reconciliation. It cannot be changed later.
  3. Fill in “Description: when to use it”. It is the only thing the agent sees on every task, so say what it does and when it fits.
  4. Write the “Instructions” in Markdown and, if you like, add “Resource files”, “Examples” and “Quality criteria”.
  5. Press “Create draft” and then, from its page, “Send for review”.

Note

Resource files must be text (md, txt, csv, json, yaml, py, js or sh), up to 512 KB each and 2 MB in total.

Tip

Every save creates a new version; earlier ones are kept and you can restore them from “Versions”.

Import a skill you already have#

  1. Press “Import” and choose a .zip or .md file with a skill in SKILL.md format.
  2. If one with that name already exists, type another and press “Import with this name”.
  3. Read the whole skill on the “Review” tab, where it opens when done: it stays “In review” until someone approves it.

Note

A .zip must have SKILL.md at its root and weigh 4 MB at most.

Activate it and assign it to an agent#

Only what a person approved reaches an agent: a draft or a skill in review is given to no one. This is what each role can do:

  1. As an admin, open the “Review” tab, read the content and the warnings and press “Approve and activate”. “Reject” sends it back to draft with your note.
  2. Open the active skill and go to the “Agents” tab.
  3. Pick an agent in “Choose an agent…” and press “Assign”.
  4. To take it away, press “Remove” next to the agent.
ActionWho can
Read and download skillsEvery role
Create, import and send for reviewMember, Admin and Owner
Approve, disable or deleteAdmin and Owner
Assign to an agent or remove itAdmin and Owner

Tip

If you edit an active skill, agents keep using the approved version until the new one is approved.
