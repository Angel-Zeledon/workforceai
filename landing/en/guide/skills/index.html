Skills: reusable know-how for your agents

A skill is a written guide an agent consults while working, for example how to write a weekly report or how to reconcile a bank statement. You write the method once and any agent can use it. The library already comes with 55 starter skills.

What is a skill, and what does it NOT do?

Each skill has a name, a description of when to use it and step-by-step instructions. It can include supporting files, such as templates or examples.

The agent only receives the name and description on each task. It gets the full text only if it asks for it. And a skill never gives an agent tools, connections or permissions: it only gives knowledge. What an agent can do is still decided by its role and your organization, and sensitive actions still ask for your approval.

What does the library include from day one?

There are 55 starter skills, in Spanish and English, already active. They cover sales, finance, legal, human resources, support, product, data and engineering. A few examples: bank reconciliation, lead qualification, NDA review, job description, support reply, product requirements, SQL query explainer and code review checklist.

On the cards they carry the Built-in label. Read them, use them as they are, or take one as a model for writing your own.

How do I find a skill?

  1. Open Skills in the menu.
  2. Type a word about the topic in Search skills, for example "report" or "sales". The list filters instantly.
  3. Use the status filters: All, Active, In review, Drafts or Disabled. Each filter shows how many there are.
  4. Click a card to open it. There you see its status, its source (Built-in, Created, Imported or From a task), its version and how many agents have it.
Tip. Skills that are in review open straight on the Review tab.

How do I read a skill before using it?

Inside a skill there are four tabs: Content, Review, Versions and Agents. Content shows the description, the instructions and the supporting files. Review shows everything an agent would receive, together with the warnings from the automatic scan, for example if the text seems to try to bypass rules or if it includes a script.

Scripts are stored as text and never run on their own. You can download any skill as a .zip or as a SKILL.md.

How do I create a skill of my own?

  1. Click New skill.
  2. Type the Name in lowercase letters, numbers and hyphens, for example bank-reconciliation. It cannot be changed later.
  3. Fill in the Description: when to use it. It is the only thing the agent sees on each task, so say what it does and when it fits.
  4. Write the Instructions in Markdown. If you want, add supporting files, examples and quality criteria.
  5. Click Create draft. Then, from its page, click Send for review.
Tip. Every time you edit and save, a new version is created. The earlier ones are kept and you can restore them from Versions.

How do I import a skill I already have?

  1. Click Import and choose a .zip or .md file with a skill in SKILL.md format.
  2. If one with that name already exists, the app asks for another and you can choose Import with this name.
  3. When it finishes, the skill is In review and opens on the Review tab. Read it in full before activating it.

How do I activate it and give it to an agent?

Only what a person approved reaches an agent. A draft or a skill in review is delivered to nobody. Approving or disabling requires an administrator; creating, importing and sending for review require write permission on skills.

  1. An administrator opens the Review tab, reads the content and the warnings, and clicks Approve and activate. They can also Reject with a note, which sends it back to draft.
  2. Open the active skill and go to the Agents tab.
  3. Choose an agent from the list and click Assign.
  4. To take it back, click Remove next to the agent.
Tip. If you edit an active skill, agents keep using the approved version until the new one is approved. Agents in a role that includes the skill by default also receive it.
