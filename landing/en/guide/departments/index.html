Your department's Drive

Every department has its own Drive: the folders and files where people and agents work together. Here you see what changed, what is waiting for your review, and you can ask an agent for something without leaving the folder.

Where to find it#

On company accounts, the side menu starts with “Department”, followed by “Pending”, “Agents and offices” and “Settings”. Everything else is under “More”.

When you open the app, your department's Drive opens right away. The 3D office is still under “More”.

  1. Open “Department” in the side menu. The first department you belong to opens.
  2. Use the folder tree (on the left on a computer; on a phone, the “Folders” button) to move around. The folder and file you open are kept in the page address, so the browser Back button works.
  3. If you belong to several departments, use the selector next to the department name, at the top.

Note

If you are not in a department yet, you will see a notice. Admins also see “Create departments”. If you open a department that is not yours, the page says it is not available.

What the list shows#

Each row has three columns: “Name”, “Last change” (who did it: the person's name or the agent) and “Status”. The filters “All”, “To review” and “Changed today” narrow the list.

“To review” and “Proposed”#

  • “To review”: an agent wants to change that file and is waiting for your approval (nothing changes until you decide), or an agent wrote something new in that file and nobody has reviewed it yet.
  • “Proposed”: an agent wants to create a new file. The file is created only when you approve the proposal.

Approve or reject#

  1. Open the file marked “To review” or “Proposed”. The file panel opens.
  2. Check the preview and, if there are any, the earlier versions.
  3. Click “Approve” or “Reject”.

Tip

The same decisions are also in “Pending”.

Mark an agent's work as reviewed#

  1. Open a file marked “To review” because an agent wrote it.
  2. Read what it did in the preview.
  3. Click “Mark as reviewed”. It no longer shows under “To review”.

Note

If the agent changes that file again, it shows under “To review” again. To mark it you need to be able to edit the folder.

Ask for something on a folder#

  1. Open the folder you want to work in.
  2. At the bottom, type in “Ask something about this folder…”.
  3. Choose the agent in the selector. Only agents you can use are listed.
  4. Click “Ask”. The agent works inside that folder.

Ask an agent from the “⋯” menu#

In the list, click “⋯” on a file's row: “Open”, “Ask an agent…” or “Download”. “Ask an agent…” puts the file name in your request and attaches the file.

Who sees what#

  • You only see departments you belong to, and only the folders your access allows.
  • An agent can never see or change more than you can.
  • Personal and team accounts keep the usual menu.

Note

A private department is not visible from outside, not even to an organization admin.
