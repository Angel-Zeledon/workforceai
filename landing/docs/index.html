Documentación técnica de AI Workforce OS

Para quien quiere entender, desplegar o integrar AI Workforce OS: cómo está construido, qué expone la API, cómo se aíslan las cuentas y qué se puede configurar. Todo describe lo que el código hace hoy.

Empieza aquí Referencia de la API Despliegue

Conceptos

Cómo está construido y cómo razonan los agentes.

  • Arquitectura de AI Workforce OS Componentes, flujo de una petición, canal WebSocket, modelo de datos, multi-tenencia con RLS y diferencia entre simulación y modo real.
  • Runtime de agentes El runtime Python de agentes: contrato HTTP, simulación vs real, proveedores y respaldo, política de datos, herramientas, sandbox y presupuestos.

Integra

La API, la autenticación y el formato de habilidades.

  • Referencia de la API Autenticación, tokens de API, errores y rutas de /api/v1: peticiones, tareas, aprobaciones, agentes, proyectos, skills, tienda, drive y WebSocket.
  • Autenticación y multitenencia Cuentas, sesiones, doble factor, roles, invitaciones y row-level security de Postgres: cómo AI Workforce OS aísla cada organización.
  • Formato de habilidades Cómo se escribe una habilidad: carpeta con SKILL.md, frontmatter, límites, ciclo de revisión, importación, exportación y cómo llega al modelo.

Opera

Despliegue, configuración y modelo de seguridad.

  • Despliegue en producción Despliega AI Workforce OS en tu servidor con Docker Compose: Caddy con TLS automático, Postgres, Redis, copias de seguridad, actualizaciones y rollback.
  • Referencia de configuración Todas las variables de entorno de AI Workforce OS con su valor por defecto: servidor, autenticación, presupuesto, proveedores de modelo y build.
  • Modelo de seguridad Cómo se limita el daño que puede hacer un agente: bóveda de credenciales, aprobaciones, topes, kill switch, auditoría, RLS y sandbox, con sus límites.
